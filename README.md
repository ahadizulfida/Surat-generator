# Suratku SPTJM

Versi awal aplikasi pembuat Surat Pernyataan Tanggung Jawab Mutlak (SPTJM).

## Menjalankan

Buka `index.html` menggunakan peramban. Aplikasi ini tidak membutuhkan instalasi atau koneksi internet.

## Fitur

- Formulir data pemohon dan usaha
- Pratinjau surat ukuran 8,5 × 13 inci
- Validasi NIK, nomor KK, dan nama sebelum cetak
- Penyimpanan otomatis di peramban perangkat yang digunakan
- Cetak langsung atau pilih **Save as PDF** pada dialog cetak

Data hanya tersimpan pada peramban lokal, bukan dikirim ke server.
