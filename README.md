# About - Surat Generator

Berawal karena saya pusing ketika banyak orang mau bikin surat. Saya harus mengubah
banyak sekali data dan saya banyak sekali melakukan kesalahan. Kemudian saya memutuskan untuk membuat generator surat dimana saya hanya perlu mengubah data melalui form, dengan harapan membuat lebih praktis dan mengurangi human error.

## Only for Personal Use

Saya buat aplikasi ini web base tapi hanya untuk local saja, karena surat-surat ada yang memiliki data sensitif. Jadi penggunanya saya dan beberapa orang saja yang saya beri akses.

## Fitur

- Berbagai template surat yang akan terus saya tambah.
- Pratinjau surat dengan berbagai ukuran kertas.
- Penyimpanan otomatis di device yang digunakan (LocalStorage)
- Cetak langsung atau pilih **Save as PDF**

Data hanya tersimpan pada peramban lokal, bukan dikirim ke server.
